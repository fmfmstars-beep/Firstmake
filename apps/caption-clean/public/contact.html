HELP US MAKE THE REPAIR DESK BETTER

Questions or a caption that will not convert?

Email fmfm.stars@gmail.com with “CaptionClean” in the subject.

A useful bug report

Tell us which browser you used, whether the input was SRT or WebVTT, the offset and options you selected, what you expected, and the exact error message. Include a short invented example that demonstrates the issue. Two or three cues are often enough.

Do not send a private transcript, confidential subtitle file, password, payment information, or account credentials. This tool has no account system, and we do not need any credentials to investigate it.

Before you send a message

  • Check that your file is UTF-8 text and no larger than 2 MiB.
  • Make sure each cue has a start time, a later end time, caption text, and a blank line before the next cue.
  • For SRT, use commas before milliseconds. For WebVTT, use dots and include the WEBVTT header.
  • Read the guide if the issue involves offsets, clipping, or missing WebVTT layout information.

Responses

This is an independently maintained project. Messages are read as time allows, and there is no guaranteed response time or paid support service. Information you send is handled as described in the privacy policy.
