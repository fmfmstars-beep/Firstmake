About the tool

A little less manual cleanup.

TidyCSV turns a common spreadsheet chore into a short, visible workflow: choose the separator, select the repairs, and check the result.

Why this tool exists

Small exports tend to accumulate the same problems: a space before a name, an empty line at the end, or a repeated record from a combined list. Opening a spreadsheet to fix those issues can trigger other changes, such as date conversion or dropped leading zeros. TidyCSV keeps the process text-based and makes its options explicit.

A focused set of choices

The cleaner supports comma, tab, semicolon, and pipe separators, including correctly quoted multiline values. It can trim cell edges, remove blank data rows, and remove exact whole-row duplicates. It preserves row order and uneven column counts. The default formula protection adds an apostrophe to potentially active spreadsheet values; the guide explains its tradeoff for signed numbers.

The tool does not claim to clean every possible dataset. It has a 2 MiB UTF-8 input limit, does not merge records by a key, and does not infer column types. A strict parsing error is preferable to quietly guessing when quoting is broken.

Built around local processing

The working data stays inside the page in your browser. There is no account, backend CSV upload, or saved document history. The public website is delivered by Cloudflare Pages. You can read the privacy notice for the difference between ordinary website requests and file processing.
