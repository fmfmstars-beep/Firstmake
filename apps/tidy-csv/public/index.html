Exports often collect extra spaces, repeated rows, and empty lines along the way. TidyCSV handles these small repairs without asking you to build a spreadsheet formula or upload a document.

Every option has a visible effect. Duplicate removal compares the whole row, keeps the first occurrence, and respects letter case. Uneven rows stay uneven: the tool does not invent missing values, rename columns, or drop extra cells.

Good to know

Questions before you clean

Does my file leave my device?

The tool reads files and processes text in your browser. It does not send CSV contents to a server, and it does not store your input between visits. The hosting provider still handles ordinary page requests. Read the privacy notice for details.

Will it remove repeated values in one column?

No. Exact duplicate removal compares the entire row after optional trimming. Two rows with the same email but different names are both kept. Check duplicates based on a specific key in your spreadsheet or database.

What if the file has broken quotes?

Malformed quoting produces a readable error rather than a guessed result. Put any cell containing a delimiter, newline, or quote inside double quotes, and write an embedded quote as two quotes. The guide includes examples.

Does it change dates, numbers, or leading zeros?

It does not detect data types. A value such as 00123 stays 00123 in the CSV text. The default formula guard adds an apostrophe to signed values such as -12. A spreadsheet may apply its own conversions when opening the file; use its text-column import settings when exact values matter.

Which file formats work?

UTF-8 delimited text up to 2 MiB, using comma, tab, semicolon, or pipe separators. Excel .xlsx files, legacy text encodings, and very large datasets are outside the tool’s scope. Export those files as UTF-8 CSV or TSV first.
