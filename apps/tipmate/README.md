# tipmate

Self-contained browser utility. Edit index.html, style.css and app.js, core.mjs. worker.mjs embeds those exact sources for Cloudflare deployment. No account, API key, tracking, advertisements or payments.

Bill and shift arithmetic uses integer cents and half-up rounding. Currency selection changes the display label only.
