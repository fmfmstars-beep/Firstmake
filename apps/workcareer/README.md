# workcareer

Self-contained browser utility. Edit index.html, style.css and app.js. worker.mjs embeds those exact sources for Cloudflare deployment. No account, API key, tracking, advertisements or payments.

Applications, checklist and notes are saved to this browser only. Download backups before clearing storage.

Target: https://workcareer-app.fmfm-stars.workers.dev/
