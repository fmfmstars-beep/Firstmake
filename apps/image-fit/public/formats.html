Choose an output format

PNG, JPEG or WebP?

The smallest file is useful only if it still looks right and the receiving application accepts it. Start with the content and destination rather than assuming one format always wins. ImageFit Desk accepts static PNG, JPEG and WebP and exports through your browser's canvas encoder. Results can differ between browsers.

PNG: crisp detail and transparency

PNG uses lossless compression for the pixel data it stores and can preserve transparent areas. It is often a good choice for interface screenshots, simple diagrams or graphics with hard edges. Its file size depends strongly on the picture: an image full of photographic detail may be much larger than a flat-colour graphic with the same dimensions.

Lossless encoding does not make the whole editing process lossless. Resizing changes pixels, and browser decoding can affect colour. ImageFit Desk re-encodes PNG without a quality control and does not promise to reach a requested KB target. An exported PNG can be larger than its source.

JPEG: photographs without transparent areas

JPEG offers a quality and file-size tradeoff for photographs. Lower quality usually reduces the file but may create blocks, soften fine detail or add fringes around text. Inspect those areas before choosing an aggressive setting. Repeated JPEG exports can compound these changes, so return to the original when trying another setting.

JPEG does not support transparency. This tool fills transparent areas with white before JPEG export. A cutout that looked right on a dark background may therefore gain a visible white rectangle. Use PNG or WebP when the transparent background is part of the design.

WebP: another option when accepted

WebP supports transparency and can offer useful file sizes for a range of images. This tool's WebP workflow varies browser encoding quality to try your chosen budget. Compare the preview and the actual byte count with a JPEG or PNG export; the best choice depends on the source. Check the upload destination's format list, because a site or desktop application may accept JPEG and PNG but reject WebP.

Static images only

Some PNG and WebP files contain animation. ImageFit Desk rejects animated APNG and WebP rather than deliberately reducing them to one frame. GIF, HEIC and SVG are also unsupported. For animation, use an editor that handles timing and frames. For a vector graphic, choose the required export dimensions in a vector editor first.

Keep the original and verify the export

Canvas output does not preserve source metadata. That can change orientation handling, colour appearance and other information compared with a specialised image editor. This tool is for practical web exports, not exact archival reproduction or verified removal of identifying information. Keep your original, compare the result visually and test the downloaded file where it will be used.
