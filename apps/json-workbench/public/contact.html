FEEDBACK HELPS

Contact

Have a formatting problem, an accessibility issue or an idea that would make the workbench more useful? Send us a note.

Email

fmfm.stars@gmail.com

JSONWorkbench is operated by Fmfm Stars. This email address is our contact point for support, site feedback and privacy questions. Replies depend on availability; we do not promise a specific response time.

For a useful bug report

  • Tell us which action you used: Validate only, Format JSON, Minify, Copy output or Download JSON.
  • Include the exact error message, browser name and whether you were using a phone or a computer.
  • Provide the smallest fictional JSON example that reproduces the problem.
  • Describe what you expected and what happened instead.

Do not send passwords, tokens, private payment details or real customer data. We do not need the complete production document to investigate most formatting issues.

Before you write

The JSON guide explains duplicate keys, safe numeric ranges, file limits and the difference between formatting and schema validation. The privacy policy describes local processing and hosting information.
