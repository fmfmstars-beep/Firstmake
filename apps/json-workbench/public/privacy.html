YOUR DATA, EXPLAINED

Privacy policy

Last updated: October 3, 2026

JSONWorkbench formats your documents in your browser. We do not receive the JSON that you paste or open with this tool.

Document processing

The formatting, validation, key sorting and summary functions run locally in JavaScript. File selection reads the chosen file into the page’s memory. The tool does not send that document to a server or store it in local storage, session storage, cookies or a database. Reset removes the page’s current input and output. Reloading or closing the page can clear them as well.

Copying and downloading

Copy output writes text to your device’s clipboard only when you request it. Download JSON creates a file through your browser. Clipboard history, downloaded files, browser extensions and device backup features are controlled by your browser or operating system. The tool cannot remove copies stored there.

Hosting information

This website is hosted on Cloudflare Pages. Visiting it sends normal web request information, such as your IP address, requested URL and browser headers, to the hosting provider. Cloudflare may process that information for delivery, security and service operations under its privacy policy. Do not put private JSON into a page URL or a support message.

Cookies, analytics and advertising

The tool sets no cookies and currently loads no third-party analytics or advertising scripts. A static Google AdSense ownership metadata tag identifies the publisher during site review; it does not load an advertisement. If advertising or analytics is introduced, this policy and any necessary user choices will be updated before those features are enabled.

Messages you send us

If you email support, your email provider transmits the information you choose to share, including your address and message. We use it to respond to your request. Please use a fictional or redacted example when reporting a problem and do not send passwords, access tokens or customer records.

Questions

Contact fmfm.stars@gmail.com with questions about the site or this policy. We do not sell the documents entered into this tool because we do not receive them.
