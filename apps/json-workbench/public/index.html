Before you paste

Does my JSON leave this device?

The tool reads and transforms the text in your browser. It does not upload JSON to our server, use analytics or save your document in browser storage. Avoid sensitive data on shared devices, and remember that your browser, clipboard and operating system are outside this tool’s control.

What does the large-number safeguard do?

Numeric values outside ±9,007,199,254,740,991 are rejected. Put account IDs, order IDs and other large identifiers inside double quotes. Numeric tokens within the limit retain their original decimal or exponent spelling in the output.

Can I use comments or trailing commas?

No. This tool accepts standard JSON, which requires double-quoted strings and keys. JavaScript object literals, JSON5 and JSON with comments need to be converted first.

Are files saved automatically?

No. Download creates a new file on your device when you ask. Your input file is never overwritten. Reloading or leaving the page can clear your work.
