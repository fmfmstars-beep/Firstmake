Know what you are buying.

When do limits reset?

Daily limits reset at 00:00 UTC. Pro’s character counter resets on the first day of each UTC calendar month, independently of the subscription renewal date. Unused characters do not roll over.

What counts toward the allowance?

A cloud translation attempt uses the request allowance and, on Pro, its input characters. A failed provider request can still count in this beta. Reusing a cached result in the same tab and using the local subtitle tool do not call the translation service.

Can translation ever pause?

Yes. There is a shared beta capacity limit of 200 cloud translation attempts per UTC day and a limit of 6 attempts per minute per network. These limits also apply to Pro. Cloud capacity will be reviewed before sales open.

How does cancellation work?

When subscriptions open, use Account → Manage billing / cancel. Cancelling renewal keeps access until the end of the paid period. Review the final terms and total, including any applicable tax, before confirming a purchase.
